## Exact missing title-specific evidence

- **Source bytes:** the original XEX hash is preserved, but a native plan still
  needs precise decompressed byte-source identities and independently checked
  offset/extent/initialization coverage for every proposed region.
- **Zero fill:** explain what the disputed tail must contain and why. A PE size,
  native allocation or other game's zero policy alone does not justify it.
- **Relocation:** prove fixed guest placement is sufficient or independently
  specify/test required fixups; current synthetic validator rejects relocation.
- **Guest layout:** independent address/range plan for code, constants, data,
  heaps, stacks, TLS, aliases, neighbors and unknown holes, with collision and
  partial-page permission policy. Native ownership can be newly constructed;
  it must not be mislabeled as observed Xbox ownership.
- **Startup registers:** consumed r1/r2/r13, GPR/FPR/LR/CTR/CR/XER/MSR values and
  calling/return obligations require title provenance. Synthetic constants are
  not evidence for those values.
- **TLS:** original template content, raw/zero size, slot policy, process/module
  relationships and per-thread initialization need exact contracts.
- **Imports:** identify actual required initialization/import paths and preserve
  unsupported-signature denials; this new workload exercised only one of the
  four existing selected contracts. Full Xbox kernel/ABI is not implemented.
- **Permissions:** prove selected data/code permissions and all dynamically
  consumed pointer ranges; logical checks are not full Horizon VM isolation.
- **Ownership/lifetime:** bind actual source/semantic plan/code/runtime identity,
  fresh load instances, active calls/threads/capabilities, unload and rollback;
  no adjacent allocation can substitute for missing image backing.
- **Exception/refusal:** show that the proposed restricted scope can terminate
  before every unsupported continuation with observable failure. If functionality
  requires guest handler search/unwind/continuation, it requires separate proof.
  Host catch blocks and the explicit denial seam do not supply Xbox semantics.
