# Phase 10 generated-memory instrumentation

Original encoded PPC words, original expected bytes/register values, the pinned
SDK decoder/builders/templates and the Phase 9 checked allocation backend. No game
input or generated game code is compiled/executed. All output must remain private.

```sh
python3 tools/sdk/build.py --lock tools/sdk/instrumentation-lock.json \
  --workspace "$PRIVATE/phase10-sdk" --cmake "$CMAKE" --ninja "$NINJA" --clean
# Wait for this one builder to finish all three profiles before testing.
for profile in Debug Release Sanitized; do
  flags=()
  if [ "$profile" = Sanitized ]; then flags+=(--sanitize); fi
  python3 tests/instrumentation/run.py --sdk "$PRIVATE/phase10-sdk/staged/$profile" \
    --source "$PRIVATE/phase10-sdk/sdk" \
    --workdir "$PRIVATE/instrumentation-$profile" "${flags[@]}"
done
python3 tests/instrumentation/test_audit.py
```

The loop uses bash/zsh arrays. Do not run two SDK builders against one workspace.
The runner requires completed SDK metadata, verifies the library hash and rejects
sanitizer-profile mismatches. Each compiler/program runs in a child session with
an external 30-second watchdog. Expected typed-vector compilation failures are
recorded separately and their diagnostic must match the intended type constraint.

The real template is rendered twice: default behavior and checked behavior selected
at compilation with `REX_CHECKED_ACCESS_HEADER="runtime/generated_access.h"`.
The original emitted instruction bodies are identical in both modes. The SDK's
other test-PCH template is compiled for its new vector/guard seams too.

32 original cases cover scalar, finite FP memory, reverse-endian operations,
MMIO hints, full vectors, refused atomics/partial vectors and guarded calls.
The checked executable passes null as the generated arena base; its supported
accesses resolve opaque handles through the scope. Scope registration is trusted
host setup, not a native-code sandbox. The header's comments and [report](../../docs/research/generated-memory-instrumentation.md)
define quiescence, lifetime, ownership, alignment and exception limitations.

The lexical fixture gate and preprocessor macro check detect known seam drift.
They cannot prove arbitrary C++ safety. Timing uses the same original aligned
64-bit generated load, 256 iterations per sample and five samples; it reports the
median and matching checksums. Default is a real in-bounds native memory baseline.
Scheduling, profiling, optimization and sanitizers affect timing; no game-speed
prediction or stable slowdown guarantee follows. Object `__text` size isolates
emitted functions plus their reachable helpers; full object size includes debug data.

Run older unified suites per the [Phase 9 recipe](../guest-memory/README.md), using
this new staged SDK and `--pre-entry` on the unified runner. Preserve historical
component/source-leaf and VMX controls, watchdog and static-audit unit tests.

Static private assessment only:

```sh
python3 tools/audit_instrumentation.py --generated "$PRIVATE_GENERATED" \
  --output "$PRIVATE/phase10-static-assessment.json"
```

No existing game output is rewritten or regenerated by this tool. Its reports
contain no function addresses/snippets, and stay outside public Git.
